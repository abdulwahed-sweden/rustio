{# Phase 6.2 — shared FormField renderer. Renders one row for one FormField object. Caller iterates `fields` (or `section.fields`) and includes this for each item; the include inherits the parent context's `field` loop variable. Supports the FormField shape from rustio-core/src/admin/render.rs: name, label, widget ("input"|"checkbox"|"textarea"|"select"), input_type, value, hint, placeholder, required, options, multiple, span (caller wraps with col-span-2 if span==2; this include is scope-agnostic), autocomplete, autofocus, disabled, maxlength, searchable, has_more, search_url, errors. Used by the generic admin form (form.html) and by every bespoke form (login, password_change, user_new, user_edit, group_new, group_edit) so all standard inputs share one rendering path. Phase 7.5 — per-field validation errors. When `field.errors` is non-empty, the input gets `aria-invalid="true"` + `aria-describedby` pointing to a sibling error block. Empty `field.errors` keeps `aria-invalid="false"` and skips `aria-describedby` (no element to reference). Bespoke validators populate the keyed errors via `apply_field_errors`; the generic AdminEntry path passes the empty map and renders the global error banner only. #}
