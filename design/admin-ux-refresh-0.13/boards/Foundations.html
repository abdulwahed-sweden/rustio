Scope of this proposal

Foundation
Locked, with one amendment. Palette, font stack, radii, 240px rail, control density and status colours are inherited untouched. The type scale was raised on 2026-09-18 for legibility: body 16/500, table cell 15/500, mono labels 13/700, and a hard floor of 13px for any text a user relies on.
Component
Inherited. Four additions assembled from existing parts: a selection bar, a sortable column head, a row skeleton, and a role option card.
Layout
Redesigned. Toolbar in two rows and three zones; pagination gains rows-per-page; cards carry Title / Subtitle / Badge / Timestamp; the edit form groups fields and pins its actions.
Interaction
Redesigned. Active filters read as filled fields; sorting moves into the column head; multi-select with bulk actions; the composer previews the row it is composing.
Architecture
Redesigned. The view composer becomes a two-pane editor — field list on the left, one field’s settings on the right — so it scales past six fields instead of widening a grid of selects.
