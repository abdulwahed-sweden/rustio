Sign In

The smallest screen in the product and the only one an unauthenticated stranger sees. What it needs is precision in its states, not a new composition.

A

Purpose

One task: authenticate. Everything that is not the email field, the password field and the button is a distraction. The card already does this well; the work here is the failure paths.

Sign in
  • Card min(100%, 420px), centred on both axes, 24px padding, 14px radius, 1px --border, full panel shadow.
  • Brand block left-aligned with the form. One alignment per card.
  • Fields 16px apart; the submit is full width and the only blue on the page.
  • The alert sits between the brand block and the form, 16px above the first field.

Proposals and product status

Error copy names the fix, not the failure

“That didn't match — check the email and password and try again”, with the email preserved. Never distinguish “no such user” from “wrong password”.

Visual / UX only

The password field carries the error state, the email does not

Visual / UX only
