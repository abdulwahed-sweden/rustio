Bookflow·v2.0.5
  • Two columns, 1.35 : 1, 24px gutter, on the wide measure. The preview column is position:sticky so it stays in view down a long field list.
  • The field list is a stack of rows, not a spreadsheet. Four columns — Order, Field, Role, Display label. Filter becomes one checkbox under the list; Merge is a per-row control revealed on the row it applies to.
  • Field identity is two lines: the human label at 15px/680 above the backend column name at 13px mono.
  • Hidden rows render at 55% opacity — present, ordered, obviously inert, still reorderable.
  • The selected row takes --blue-soft, tying it to what it controls in the preview.
  • Value labels collapse into one <details> per field, first open. They are translation work, not composition work.
  • The role matrix is a reference card: five roles × four layouts, filled dot = shown. It documents the renderer's fixed role sets.

Existing behaviour

Live preview

One real record rendered in the selected layout, updating as roles and labels change, client-side, with no page load and no save. The page must carry one sample row plus the role sets the renderer uses; the preview re-renders from form state. No new endpoint, no change to ViewSpec semantics, nothing persisted until Save view. With no records, the preview renders labelled placeholders rather than disappearing.

Backend wiring

Filter checkbox gated by role

A filter is only meaningful on a badge-shaped column, which is the rule the derivation already applies. Presenting it per-row invited setting it on a timestamp.

Backend wiring

Drag to reorder

Replacing ▲▼ with a drag handle. ▲▼ stay regardless — they are the keyboard-accessible path. Deferred until pointer, touch and keyboard parity is worth having.

Future

Per-user saved views

“Save as my view” beside “Set as default”. Needs a per-user ViewSpec store and a resolution order.

H

Visual acceptance

  • The effect of a role change is visible without leaving the page.
  • Field rows no longer read as a spreadsheet: human label and backend name are on separate lines.
  • Hidden fields are visibly inert but still reorderable.
  • Value-label tables are collapsed by default and do not push the composer below the fold.
  • Exactly one blue button on the page, and it is Save view.
  • The preview is clearly labelled as a preview and states that nothing is saved until Save view.
  • At 900 and below the preview appears above the composer.
  • No horizontal overflow at 390.
